# 多子题 Flag 逐步提交与实时查看实施记录

日期：2026-10-09
对应计划：[multi-flag-progress-plan.md](multi-flag-progress-plan.md)
状态：MF01–MF05 已实施，确定性验收通过。未执行真实模型验证。

## 功能与契约

### MF01：及时提交与子题标签

初始提示词、续轮提示词、公共工作流指引和工具描述统一要求：每得到一个有证据支持的候选，先提交原文再继续其他已知子题，不等待完整验证、全部完成或摘要更新；缺少检查时如实说明。第一条候选不代表整体完成，不凭空推断还有其他 Flag。结束时说明剩余项，有部分成果时优先保留为 `candidate_unverified`。

`candidate_submit` 新增可选 `subtask`，最多 160 字符。字段进入候选记录、`candidate_recorded` 事件、证据详情、工具返回、`state_read` 与上下文恢复；大记录摘要也保留标签。缺省为空，在界面显示“未标注子题”。标签不改变验证状态，不按候选原文全局去重。

### MF02：多候选结束汇总

`run_complete` 新增可选 `candidate_ids` 列表，继续接受 `candidate_id`。归一化时先取单字段，再按列表顺序合并，去重且保序；全部 ID 都必须存在于当前运行。`candidate_unverified` 至少需要一个 ID；`unsolved` 保持原有语义，若提供 ID 也必须合法。

完成记录、证据详情、工具返回、诊断索引与 Markdown 报告保留完整列表。旧单字段保持原值；仅提供列表时，单字段取列表第一条，方便旧消费者读取。候选历史和 `RunResult.candidate_ids` 仍保留全部提交记录，不因最终汇总未选择而删除。旧完成事件仅有单字段时，报告仍可显示该 ID。

### MF03：运行中入口与隔离

App 在 UI 线程维护候选集合。运行开始即可打开 `Flag · 0`，成功提交后显示实际候选数量，并短暂通知已记录的子题与 ID，不自动弹窗、不抢焦点。

展示依据是落盘后的 `candidate_submit` 工具结果和通过 hash、长度及路径校验的原文证据，不解析普通模型文本、不提前使用调用参数。初始化事件提供运行 ID 与证据目录，无需等待 `last_result`。

按当前运行内的候选 ID 去重；新预览和新运行清空集合。工作线程消息携带运行代次，旧代次消息丢弃；事件的运行 ID 不匹配时也丢弃。结束后打开窗口会重新校验证据并从日志重建，兼容没有子题标签的旧记录。

### MF04：动态窗口与稳定复制

窗口显示候选 ID、子题、未验证状态、候选数量和运行状态。空窗口第一条到达时自动填充，之后只更新列表，不主动切到新候选。更新选择项时抑制程序触发的选择变更消息，不重新加载当前文本，保留文本选区、滚动位置和复制状态。挂载后再同步一次，覆盖候选在弹窗挂载期间到达的时序。

完整复制按钮在点击时固定所选原文，后台新增候选不改变正在复制的值。已有跨平台复制与选区复制实现不变。关闭窗口仅返回主界面；自然结束、停止或运行错误后，已有候选仍可查看。

Textual 8.2.8 的 App 控件查询指向默认屏幕，后台消息可继续更新主运行视图；布局操作也明确使用 `default_screen`，避免对弹窗修改运行视图样式。历史手动跟踪策略、statusline 和取消累计额度的行为均保持。

## 验证

新增 `tests/test_multi_flag_progress.py`，使用合成 provider、受控线程同步点与模拟剪贴板。覆盖：

- 提交 A → 实际执行第二子题命令 → 提交 B → 多结果结束。
- 单字段、列表、两字段合并、空列表、未知/非当前运行 ID 的完成契约；超过 32 条候选汇总、未选中候选保留和旧报告兼容。
- 缺省、中文、160 字符与控制字符标签；超长标签拒绝；状态读取与恢复保留标签。
- 运行结果尚不存在时打开空窗口；A 到达后查看、复制，复制未结束时 B 到达；A 的选区、滚动和复制原文保持稳定。
- 关闭重开、自然结束与用户停止后继续查看；候选数量、重复事件、失败提交、迟到事件及新运行隔离。
- 非第一项选中时追加候选仍保持所选项；弹窗挂载期间到达的候选不会丢失。
- 弹窗打开期间主视图、上下文 statusline 与运行消息处理继续工作，手动历史跟踪状态保持。

## 范围

未增加比赛平台自动提交、Flag 自动提取、正确性判定或跨运行续解，也不因第一条 Flag 停止运行。原文、未验证状态、单次工具超时与输出长度保护继续保留；后续已取消任务级轮次和总时长限制，累计 token、工具调用次数与回复字节数仅用于统计，详见 [额度与用量显示修改](unlimited-task-usage-implementation.md)。
