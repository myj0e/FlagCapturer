## 3. 不纳入通用修复的领域问题

- 模数分解方法、特殊 RSA 弱点、ECM 参数和专用分解器能力属于 Crypto 工作流；通用层只负责表达方法适用条件、成本、实际能力和停止策略。
- ELF 字符串地址、反汇编和原程序输入检查仍由 [Reverse 专用计划](reverse-evidence-improvement-plan.md) 负责。
- 尚未证明装某个分解器、增加次数或换模型必然得到答案。不能把“调用次数耗尽”误写成此次未解出的唯一原因。
- 不直接比较两次运行的工具总数作为退步证据：第二次恢复了正确参数、完成更多有效数值尝试，也承担了新增来源校验；真实效果需要受控重复实验。
