# Textual fake-event spike

This is isolated Stage A code. It does not invoke a model, shell, runtime, network, or challenge. It intentionally shows synthetic event flow, a fake session input, long output, and terminal control characters. It is not included in the `ctfbot` package.

Create a temporary environment and install `textual==8.2.8` before running. Record the exact Python/Textual version, terminal emulator, terminal dimensions, color mode, resize behavior, key focus behavior, and safe rendering results in [`../../tui-spike.md`](../../tui-spike.md).
