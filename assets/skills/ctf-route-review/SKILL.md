# Reassess the current route

Read current claims, experiments, observations and the newest user guidance using state_read/observation_get. Recover cited raw records when the summary omits scope. Keep this public and concise; do not expose private reasoning.

- Separate observed facts, user hints, implementation assumptions and unknowns. A user-provided URL is unread until its content is available.
- Identify the common assumption behind recent variants. Command differences alone do not make distinct hypotheses. Ask what new evidence each produced.
- Check whether original evidence was fully inspected: a rendered image excludes trailing bytes, a listed archive may contain nested content, truncated output does not establish absence. Use relevant format inspection, not a universal checklist.
- Distinguish algorithm validity from task correspondence. Invertibility, continuity, valid syntax and zero exit codes prove limited properties, not the intended decoding.
- Choose the smallest next probe that separates competing explanations. Give its evidence-based parameters, expected observations and what each outcome would change.
- Keep a short public update only when a meaningful decision changes. Claims/experiments are optional aids; there is no required review record, category switch or fixed solve budget. Periodic maintenance already consolidates executed attempts and their scope; choose the next useful action yourself from actual evidence.
- Historical suggestions are replaceable. Recheck their basis when new evidence arrives; an unexecuted suggestion is not an obligation or a result.
- When a required source or capability is missing, report it immediately. Preserve saved evidence and explicit unresolved work; use run_complete if no useful available action remains.
