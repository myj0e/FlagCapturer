# Stego workflow v1

Inspect the carrier dimensions, structure and metadata before guessing LSB encodings. The PPM helper tests one documented fixture hypothesis only; failure does not rule out steganography. For PNG compare chunk types and CRCs. The extended toolbox includes zsteg with its Ruby image parsing dependencies and SoX with the full format plugin package. Use zsteg for PNG/BMP bit-plane hypotheses and SoX for offline audio inspection or transformations. Check workflow_environment first, bound scans and write derived files under /work. These tools do not provide model-side visual image input; compressed pixel transforms may still require bounded scripts.

When image_view is available, inspect the original carrier before choosing a visual hypothesis. Use a focused crop for small markings or text. Save extracted channels, bit planes or selected animation frames as /work images, then inspect them on demand; tool metadata alone is not visual inspection. Preserve the original input and record each transformation and source observation. Visual resemblance is not proof of a decoded flag.

## Execution and verification

Use workflow_environment before workflow_run. Inputs are read-only paths relative to /challenge; scripts and extracted files go to /work. Inspect artifact hashes and lineage. Submit the flag using candidate_submit to complete that requested objective. Continue only actual remaining subtasks, then include an agent-authored Markdown writeup in run_complete; platform acceptance is never pending work. Output caps, timeouts and missing dependencies must be retained in evidence.

## Coverage limits

This is a beginner workflow, not full category coverage. The representative authored fixture checks one mechanism; no live model solve rate or generalization claim has been established. Source and license inventory is in pack.yaml.
